# Aviyansh Manchanda — Portfolio

A responsive, single-page personal portfolio website.

## Files

- `index.html` — the complete website. No build step, package installation, or server is needed.
- `aviyansh-portfolio.zip` — a downloadable copy of the website for deployment.

## Preview locally

Double-click `index.html` to open it in a browser.

## Deploy with Netlify

1. Go to [Netlify Drop](https://app.netlify.com/drop).
2. Drag in `aviyansh-portfolio.zip`, or drag in the folder containing `index.html`.
3. Netlify will publish the site and give you a link.

## Deploy with Vercel

1. Create a new GitHub repository and upload `index.html` and this README.
2. Sign in to [Vercel](https://vercel.com/) with GitHub.
3. Select **Add New → Project**, then import the repository.
4. Click **Deploy**. No framework settings are required.

## Deploy with GitHub Pages

1. Create a repository named `AviyanshM.github.io` on GitHub.
2. Upload `index.html` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder, then save.
6. Your site will be available at `https://AviyanshM.github.io` after GitHub finishes publishing it.

## Updating content

Open `index.html` in any code editor and update the text, links, or project cards. The design and all styling are contained in this one file.
